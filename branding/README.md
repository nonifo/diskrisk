# Branding assets

Place optional UI assets in this directory:

| File | Role |
|------|------|
| `logo.svg` | Header logo (default `DISKRISK_LOGO`) |
| `favicon.ico` / `favicon-96x96.png` | Browser favicons |

Override with `SMART_RISK_BRANDING`, `DISKRISK_LOGO`, and `DISKRISK_BRAND_URL`
in `config.env`. If no logo file is present, the UI shows the product name only.

Sample files shipped here are placeholders for local demos — replace them for
your own deployment.
